# Kisan Connect — Frontend (Pratham's modules)

React + Vite frontend for the Kisan Connect marketplace.

## Stack
- React 18 + Vite 5
- React Router v6, Zustand
- Tailwind CSS, Lucide icons, Recharts, React Leaflet, sonner, axios

## Pratham's modules
- Admin Dashboard + User Management + Orders + Grievances + Analytics (`/admin/*`)
- Kisan Mitra chatbot widget (global, EN + HI)
- Driver PWA (`/driver`, `/driver/delivery/:id`)

## Run
```bash
npm install
npm run dev      # http://localhost:3000
```

## Environment
Copy `.env.example` to `.env` and set `VITE_API_URL`.
